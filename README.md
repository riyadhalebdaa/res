# استبيان رضا بالوجوه التعبيرية

ملفات موقع ثابت مناسب للنشر على GitHub Pages.

## 1) إعداد البريد
افتح `index.html` وابحث عن:

`https://formsubmit.co/YOUR_EMAIL@example.com`

واستبدل `YOUR_EMAIL@example.com` بالبريد الذي تريد استقبال النتائج عليه.

## 2) إعداد صفحة الشكر
ابحث عن:

`https://YOUR-USERNAME.github.io/res/thanks.html`

واستبدل الرابط بعنوان موقع GitHub Pages الفعلي.

## 3) النشر على GitHub Pages
ارفع `index.html` و`thanks.html` إلى المستودع، ثم:
Settings → Pages → Deploy from a branch → اختر الفرع `main` والمجلد `/ (root)`.

## 4) أول إرسال
في أول مرة، ستطلب FormSubmit تأكيد البريد المستلم. بعد التأكيد يمكن استقبال الاستجابات عبر البريد.

ملاحظة: هذا النموذج لا يحتوي على خادم خلفي؛ GitHub Pages يستضيف الملفات فقط، بينما FormSubmit يتولى استقبال البيانات وإرسالها بالبريد.
